Common Questions

What counts as an operation?

Each API call to sign, verify, encrypt, decrypt, or attest counts as one operation. Batch calls count as the number of items in the batch (e.g., 500 messages in a batch = 500 operations).

Can I upgrade or downgrade anytime?

Yes. Upgrades take effect immediately. Downgrades take effect at the end of the current billing period. Your API key stays the same.

What happens if I exceed my limit?

API calls return a 429 status code with a Retry-After header. No overage charges. Upgrade your tier or wait for the limit to reset.

Do you offer annual billing?

Contact sales@cyclecore.ai for annual plans with discounted pricing.
