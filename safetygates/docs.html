Quick Start

Get your free API key at sg-api.cyclecore.ai/signup

cURL

curl -X POST https://sg-api.cyclecore.ai/v1/classify \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"text": "you are trash", "gates": ["toxic"]}'

Response

{
  "results": {
    "toxic": {
      "label": true,
      "confidence": 0.89
    }
  },
  "latency_us": 1234.5
}

Node.js

const SafetyGates = require('safetygates');
const client = new SafetyGates('YOUR_API_KEY');

const result = await client.classify('you are trash', ['toxic']);
console.log(result.results.toxic.label); // true

Python

import requests

response = requests.post(
    'https://sg-api.cyclecore.ai/v1/classify',
    headers={'X-API-Key': 'YOUR_API_KEY'},
    json={'text': 'you are trash', 'gates': ['toxic']}
)
print(response.json()['results']['toxic']['label'])  # True

Authentication

Include your API key in the X-API-Key header:

X-API-Key: sg_live_xxxxxxxxxxxxx

Or use Bearer token format:

Authorization: Bearer sg_live_xxxxxxxxxxxxx
Demo Key

Use demo as your API key to test without signing up. Limited to 100 requests/day.

Endpoints

Base URL: https://sg-api.cyclecore.ai

POST /v1/classify

Classify a single text against one or more gates.

Request Body

Parameter Type Description
text required string Text to classify
gates optional array Gates to check (default: ["toxic"])

Response

{
  "results": {
    "toxic": { "label": true, "confidence": 0.89 },
    "spam": { "label": false, "confidence": 0.12 }
  },
  "latency_us": 1456.7
}
POST /v1/classify/batch

Classify multiple texts in a single request (up to 10,000).

Request Body

Parameter Type Description
texts required array Array of texts to classify
gates optional array Gates to check (default: ["toxic"])

Response

{
  "results": [
    { "toxic": { "label": false, "confidence": 0.1 } },
    { "toxic": { "label": true, "confidence": 0.94 } }
  ],
  "total_latency_us": 2345.6,
  "items_per_second": 852.4
}
GET /v1/gates

List all available classification gates.

GET /health

Health check endpoint. No authentication required.

Error Codes

Code Description
400Bad request - Invalid parameters or unknown gate
401Unauthorized - Missing or invalid API key
429Rate limit exceeded
500Internal server error
503Service unavailable - Gates not loaded
