Privacy Policy

Effective Date: January 11, 2026

Summary: We don't store your content. We don't sell your data. We don't train on your inputs. We collect only what's needed to run the service.

1. Who We Are

SafetyGates is operated by CycleCore Technologies LLC, a Wyoming limited liability company.

Contact: privacy@cyclecore.ai
Website: https://cyclecore.ai

2. Data We Collect

Data We DO NOT Collect or Store

  • Input text — The text you send for classification is processed in memory and immediately discarded. We do not store, log, or retain your content.
  • Classification results — API responses are not logged or stored on our servers.

Data We DO Collect

Data Type Purpose Retention
API key identifier Authentication, usage tracking Account lifetime
Request metadata Billing, rate limiting 90 days
Email address Account management, billing Account lifetime
Payment information Billing (via Stripe) Per Stripe's policy
IP address Security, abuse prevention 30 days

Request metadata includes: timestamp, response latency, text length (character count only, not content), error codes.

3. How We Use Your Data

  • Service operation — Authentication, rate limiting, API routing
  • Billing — Usage-based billing calculation
  • Security — Abuse detection, fraud prevention
  • Improvement — Aggregated, anonymized metrics to improve service performance

We do NOT:

  • Sell your data to third parties
  • Use your input data to train AI models
  • Share your data with advertisers
  • Profile you for marketing purposes

4. Data Sharing

We share data only with:

  • Cloudflare — CDN, DDoS protection, TLS termination
  • Stripe — Payment processing (for paid plans)

Both are GDPR-compliant and bound by data processing agreements.

5. Your Rights (GDPR)

If you are in the EU/EEA, you have the right to:

  • Access — Request a copy of data we hold about you
  • Rectification — Correct inaccurate data
  • Erasure — Request deletion of your data
  • Portability — Receive your data in a machine-readable format
  • Object — Object to processing for certain purposes
  • Restrict — Request limited processing

To exercise these rights, contact privacy@cyclecore.ai.

6. Data Processing Agreement

Enterprise customers may request a Data Processing Agreement (DPA) for GDPR compliance. Contact legal@cyclecore.ai.

7. Security

We protect your data with:

  • TLS 1.3 encryption for all API traffic
  • No public IP exposure (Cloudflare Tunnel)
  • API key hashing (we cannot retrieve your raw key)
  • Rate limiting and abuse detection

For more details, see our Trust Center.

8. Cookies

The SafetyGates API does not use cookies. Our marketing website may use essential cookies for functionality.

9. Children's Privacy

SafetyGates is not intended for use by children under 18. We do not knowingly collect data from children.

10. Changes to This Policy

We may update this policy periodically. The current version is always available at this URL. Material changes will be communicated via email to registered users.

11. Contact
